# 检索质量测评报告

> 所有数字均为本机实测，问题集与脚本随仓库提供，可复现（见文末）。无估算，无外推。

## 1. 目的

回答一个常被追问的问题：**混合检索（BM25 + 向量 + RRF 融合 + Multi-Query 扩展 + LLM 重排）相比单路检索，到底带来多少提升？**

## 2. 测评设置

| 项 | 值 |
| --- | --- |
| 语料 | 20 篇 arXiv 公开论文（Transformer/RAG/Agent/扩散模型/CoT 等主题），共 1369 个分块 |
| 问题集 | 21 题：术语型 10 题（含专业词）+ 口语型 11 题（大白话），每题标注正确答案文档 |
| 命中判定 | 标准答案文档的任一分块进入检索结果前 3 名记为命中（规则在跑数前确定） |
| Embedding | BAAI/bge-small-zh-v1.5（本地模式） |
| 重排/改写模型 | DeepSeek（OpenAI 兼容接口） |
| 对照模式 | 向量单路 / BM25 单路 / 混合 RRF / 混合全开（Multi-Query + LLM 重排） |

问题集见 `tests/data/eval_questions.json`，脚本见 `scripts/eval_retrieval.py`，
原始逐题数据见 `docs/evaluation-data.json`。

## 3. 结果（top-3 命中率）

| 模式 | 总体 | 术语型 | 口语型 | p50 延迟 |
| --- | --- | --- | --- | --- |
| 向量单路 | 28.6% | 40.0% | 18.2% | 8.8ms |
| BM25 单路 | 33.3% | 40.0% | 27.3% | 6.5ms |
| 混合 RRF | 38.1% | 50.0% | 27.3% | 16.3ms |
| **混合全开（Multi-Query + LLM 重排）** | **95.2%** | **100%** | **90.9%** | 21.8s |

## 4. 结论

1. **单路召回率只有 29-38%**：20 篇主题相近的论文作为语料，难度远高于日常场景（干扰项密集），单路检索对"口语化提问"尤其弱（向量单路仅 18.2%）。
2. **Multi-Query 扩展 + LLM 重排带来 90% 命中率**：LLM 把原问题改写为多视角检索式并行召回（扩大召回覆盖），再按相关性重排（把正确文档顶到前列），两步合计把命中率从 38% 拉到 95%。
3. **代价是延迟**：全开模式 p50 约 21.8s（每题 2 次 LLM 调用），因此产品形态为可选开关——日常问答用混合 RRF（16ms），深度研究开启全开模式。

## 5. 复现

```bash
# 语料：20 篇 arXiv 论文上传至书架并完成向量索引
XUEYU_DATA=<数据目录> python -m scripts.eval_retrieval
```


## 7. 统一分块口径后的复测

原始实现里向量索引按 480 字（重叠 60）切块，BM25 按 1200 字硬切，融合键取 `doc_id + 文本前 80 字`。
两路边界不同，除文档首块外几无对齐可能，RRF 实际只是把两个列表交错合并。
本次改为：向量与 BM25 共用 `split_chunks()`，每块带 `chunk_id`，融合键直接用 `chunk_id`。

语料同前（20 篇论文，1369 分块），问题集 21 题，判定规则不变，重跑结果：

| 模式 | 总体 | 术语型 | 口语型 | p50 延迟 |
| --- | --- | --- | --- | --- |
| 向量单路 | 28.6% | 30.0% | 27.3% | 10.0ms |
| BM25 单路 | 33.3% | 40.0% | 27.3% | 4.6ms |
| 混合 RRF | 38.1% | 40.0% | 36.4% | 14.2ms |
| 混合全开 | 90.5% | 100.0% | 81.8% | 8.4s |

两点如实说明：

1. **RRF 的 top-3 命中率没有变化（38.1%）**。修正的是融合语义——同一证据单元终于能在两路对齐，
   而不是两个列表交错；但 top-3 命中率对这一点不敏感，真正带来提升的是 Multi-Query 与重排。
2. **全开模式的两次独立运行分别为 95.2% 与 90.5%**，差异来自 LLM 重排的模型侧波动，
   不是代码变化。引用这组数字时应写成"90% 以上"。
3. 本轮把多查询召回改为并行（`asyncio.gather` + 线程池），全开模式 p50 从 21.8s 降到 8.4s。
